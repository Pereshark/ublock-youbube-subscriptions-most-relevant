# uBlock Origin: YouTube Subscriptions Most Relevant

A uBlock Origin filter list that hides YouTube subscriptions most relevant shelve and cards.

## Install

1. Open uBlock Origin dashboard.
2. Go to **Filter lists** → **Import**.
3. Paste the raw URL of `ublock-youbube-subscriptions-most-relevant.txt`:

```
https://raw.githubusercontent.com/Pereshark/ublock-youbube-subscriptions-most-relevant/refs/heads/main/ublock-youbube-subscriptions-most-relevant.txt
```

4. Click **Apply changes**.

## What it blocks

- Subscriptions most relevant shelve.
- Subscriptions most relevant cards.
